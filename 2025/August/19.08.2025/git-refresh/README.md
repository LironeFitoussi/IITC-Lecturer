# MyBlog - Modern Blog Website

A beautiful, responsive blog website built with vanilla HTML, CSS, and JavaScript. Features a modern design with smooth animations, mobile-first responsive layout, and interactive elements.

## 🚀 Features

### Design & Layout
- **Modern UI/UX**: Clean, professional design with beautiful gradients and shadows
- **Responsive Design**: Mobile-first approach that works perfectly on all devices
- **Smooth Animations**: CSS animations and transitions for enhanced user experience
- **Typography**: Beautiful Inter font family for excellent readability

### Functionality
- **Fixed Navigation**: Sticky header with smooth scroll effects
- **Mobile Navigation**: Hamburger menu for mobile devices
- **Smooth Scrolling**: Animated navigation between sections
- **Interactive Elements**: Hover effects and click animations
- **Newsletter Subscription**: Functional email subscription form with validation
- **Post Cards**: Interactive blog post cards with hover effects

### Technical Features
- **Vanilla JavaScript**: No frameworks, pure JavaScript for all functionality
- **CSS Grid & Flexbox**: Modern CSS layout techniques
- **Intersection Observer**: Efficient scroll-based animations
- **Local Storage**: Newsletter subscription data persistence
- **Lazy Loading**: Optimized image loading for better performance

## 🚀 Getting Started

1. **Clone or Download** the project files
2. **Open** `index.html` in your web browser
3. **Customize** the content, colors, and styling as needed
4. **Deploy** to your web server

## 🎯 Customization

### Colors
The main color scheme can be modified in `styles.css`:
- Primary Blue: `#2563eb`
- Secondary Purple: `#3730a3`
- Background Gray: `#f8fafc`
- Text Dark: `#1e293b`

### Content
- Update blog post content in `index.html`
- Modify images by replacing Picsum URLs with your own
- Customize the newsletter form functionality in `script.js`

### Styling
- Adjust animations and transitions in `styles.css`
- Modify responsive breakpoints as needed
- Update typography and spacing to match your brand
